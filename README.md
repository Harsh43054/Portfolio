# Harsh Sahu | Portfolio

A creative, scroll-driven personal portfolio website showcasing my projects, technical skills, leadership experience, and achievements. Built with plain HTML, CSS, and vanilla JavaScript, with a modern dark design and a fully responsive layout.

**Live site:** https://harsh43054.github.io/Portfolio/

## Features

- Dark, modern design with an indigo-to-cyan gradient accent
- Scroll progress bar and fade-up reveal animations (IntersectionObserver)
- Animated stat counters and floating gradient blobs in the hero
- Fully responsive, mobile-first layout
- Accessible: skip link, visible focus states, semantic HTML, and reduced-motion support
- Fast loading: no frameworks, no build step, optimized image
- SEO and Open Graph meta tags

## Sections

Hero, About, Skills, Experience, Projects, Leadership, Education and Honors, Contact.

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts: Space Grotesk and Inter

## Run Locally

No installation needed.

1. Clone the repo or download it as a ZIP.
2. Open `index.html` in your browser.

Optional local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Hosted on GitHub Pages (Settings → Pages → Branch: `main` → `/ (root)`). It also works on Netlify and Vercel with no configuration.
